📚 Banco de Dados — Livraria

Projeto simples de banco de dados em MySQL para substituir planilhas por um sistema organizado de vendas.

🧩 Estrutura do Banco

O banco possui 4 tabelas:

cliente: Dados dos clientes.

livro: Catálogo, preço e estoque.

pedido: Data e status da compra.

item_pedido: Livros e quantidades de cada pedido.

📂 Arquivos

livraria_dump.sql: Cria o banco, tabelas e insere os dados.

02_consultas.sql: 15 consultas SQL com relatórios de vendas.
